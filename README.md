# 🌐 Gyapti Trivedi - Portfolio Website

Welcome to my personal portfolio!  
This project showcases my skills, projects, and professional journey as a **UI/UX Designer** and **Web Developer**.  

---

## 🚀 Key Features
- **Clean & Modern Design**: Minimalist and fully responsive for all devices.  
- **Project Showcase**: Dedicated sections highlight my key projects, including details on technologies used and my role.  
- **About Me**: A concise, professional bio outlining my expertise and interests.  
- **Contact Information**: Easy access to my email, LinkedIn, and GitHub for recruiters and collaborators.  

---

## 🛠️ Tech Stack
This portfolio is built with:  
- **HTML** – Website structure & content  
- **CSS** – Styling, layout & visual design  
- **JavaScript** – Interactive & dynamic behavior  
- **Firebase** – Real-time data storage & management  

---

## 🌐 How to View
To view the website locally:  
1. Clone or download the repository.  
2. Open the `index.html` file in your preferred browser.  
3. Place your project and profile images in the `images/` directory and ensure correct paths in `index.html`.
