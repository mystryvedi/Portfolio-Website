Featured Projects

User Verification System

Developed a full-stack application that performed multilingual OCR processing and face verification, leveraging Tesseract to extract data from Aadhaar cards and DeepFace for biometric comparison.

Engineered the entire frontend with a focus on user experience, implementing multilingual support for six Indian languages, a responsive design, and intuitive features like light/dark mode and drag-and-drop file upload.

5G Antenna Research

A research paper on a Single-Band Modified Patch, Inset-fed Rectangular Antenna with Slots for V-Band and 47GHz mmWave Applications.

Presented a research paper at SPIN 2025 under 5G Antenna Designing domain.

Used HFSS (High-Frequency Structure Simulator) and Origin Lab software.

VR Bowling Game

Developed a two-player VR bowling game using Unity, WebVR, and A-Frame technologies, providing an immersive and stress-relieving experience for users.

Engineered a VR gaming environment by implementing a turn-based system with visual cues and creating game elements (ball, lane, pins) using primitives like a-sphere, a-box, and a-cylinder.
